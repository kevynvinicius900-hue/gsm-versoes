# Game Server Manager — versões

Aqui ficam os instaladores do **Game Server Manager**, um app para Windows que
gerencia servidores de jogos no seu PC.

## Instalar

Abra a página [**Releases**](../../releases/latest), baixe o arquivo `.msi` da
versão mais recente e abra-o.

O Windows vai mostrar **"O Windows protegeu o computador"**, porque o app ainda
não tem a assinatura paga da Microsoft. Clique em **Mais informações** e depois
em **Executar assim mesmo**.

## Atualizar

Quem já tem o app instalado não precisa voltar aqui: em **Configurações →
Verificar atualizações**, o app acha a versão nova e se atualiza sozinho. Os
servidores, os backups e as configurações ficam onde estavam.

Cada versão é assinada. O app recusa qualquer instalador que não tenha a
assinatura de quem o desenvolve.
